# Токени з макета

Макет: $ARGUMENTS

## 1. Отримай дані

- **Figma підключена** (інструменти Figma MCP): візьми змінні та стилі файлу (`get_variable_defs` або аналог) — кольори, шрифти, розміри тексту, відступи, радіуси.
- **Лише скріншот або опис** — визнач кольори й шрифти з того, що є, і познач значення «на око».
- Визнач ширину макета, ширину контейнера та бічні відступи.

## 2. Кольори і шрифти → `src/styles/variables.css`

У `:root` задай змінні з назвами за призначенням, а не за кольором:

```css
:root {
	--font-family: "Inter", sans-serif;
	--font-size: 16px;
	--main-color: #1a1a1a;    /* основний текст */
	--accent-color: #ff5a1f;  /* кнопки, посилання */
	--bg-color: #fff;
	--muted-color: #6b6b6b;   /* другорядний текст */
	--border-color: #e5e5e5;
	--error-color: #d32f2f;
}
```

- Зберігай наявні змінні `--font-family`, `--font-size`, `--main-color`: вони вже використовуються.
- Перевір контраст тексту з фоном: від 4.5:1 для звичайного тексту, від 3:1 для великого та іконок. Якщо макет не проходить — попередь, але кольори не змінюй без згоди.

## 3. Сітка → `src/styles/settings.scss`

- `$maxWidthContainer` — ширина контейнера з макета;
- `$containerPadding` — сума бічних відступів контейнера;
- `$minWidth` — лишай `320`.

## 4. Шрифти

- Файли шрифтів — у `src/assets/fonts/` (woff2; otf і ttf збірка сама конвертує), підключення генерується в `src/styles/fonts/fonts.css`.
- Google Fonts — за правилами з `src/styles/style.scss` (розділ «Підключення загальних віддалених шрифтів») або `fonts.download` у `template.config.js`.
- Ліцензійні шрифти не завантажуй сам — попроси файли в розробника.

## 5. Перед зміною

Покажи таблицю «було → стане» для всіх змін у `variables.css` і `settings.scss` та дочекайся підтвердження: ці файли впливають на весь сайт.

## 6. Перевір

`npm run dev`: сторінки відображаються з новими кольорами й шрифтами, контейнер має правильну ширину, адаптив до 320px не зламався.
