# Встановлення локального WordPress

Проєкт: $ARGUMENTS

## Доступи (лише для локальної розробки)

- Логін адміністратора: `admin`
- Пароль: `123456`
- Email адміністратора: `admin@example.com` (або той, який назве розробник)

## Кроки

1. **Docker.** Перевір `docker --version` і `docker info`. Якщо Docker не встановлений або не запущений — зупинись і попроси розробника встановити й запустити Docker Desktop.

2. **Запуск.** Виконай `npm run wp` **у фоні**: команда піднімає контейнери (`docker-compose.yml`: WordPress, MySQL, phpMyAdmin) і запускає дев-сервер у режимі WordPress. Перший запуск завантажує образи — це може тривати кілька хвилин. Команда щоразу перевіряє свіжі образи; без інтернету запускає наявні.

3. **Дочекайся WordPress** на `http://localhost:8080` (перевіряй відповідь сервера, наприклад `curl -s -o /dev/null -w "%{http_code}" http://localhost:8080`).

4. **Майстер встановлення** у вбудованому браузері на `http://localhost:8080`:
   - мова — Українська (або та, яку просить розробник);
   - назва сайту — від розробника або назва проєкту;
   - ім'я користувача `admin`, пароль `123456`, підтвердити використання слабкого пароля;
   - email адміністратора — з розділу «Доступи»;
   - «Попросити пошукові системи не індексувати сайт» — увімкнути.

5. **Налаштування після встановлення:**
   - Вигляд → Теми: активувати тему **FLS** (`fls-theme`);
   - Плагіни: активувати плагін збірки (`fls-plugin`), якщо він є;
   - Налаштування → Постійні посилання: «Назва запису»;
   - Головна → Оновлення: якщо є новіша версія WordPress, перекладів чи плагінів — оновити. Файли ядра зберігаються в `backend/wordpress`, тож новий образ docker їх не оновлює;
   - для блоків використовуй плагін SCF.

6. **Обов'язково повідом розробнику:**
   - адресу адмінки: http://localhost:8080/wp-admin
   - логін `admin` і пароль `123456`;
   - попередження дослівно:

   > ⚠️ Пароль `123456` — тільки для локальної розробки. Перед перенесенням сайту на staging чи хостинг (`wpdeploy`) обов'язково змініть його на надійний (Користувачі → Профіль → Новий пароль), інакше сайт зламають підбором пароля.

## Корисне

- phpMyAdmin — http://localhost:8081.
- Зупинка: `npm run wpstop` (дані бази лишаються в `backend/database`).
- Подальша робота з темою — правила в `src/wordpress/AGENTS.md`, блоки — скіл `fls-wp-block`.
