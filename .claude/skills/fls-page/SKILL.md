# Нова сторінка FLS

Сторінка: $ARGUMENTS

## Кроки

1. **Назва файлу** — латиницею, малими літерами, без цифр і розділових знаків (`about`, `contacts`, `thanks`). Для 404 — `404` створюй вручну за зразком `src/index.html`, бо генератор не приймає цифри.

2. **Створи сторінку генератором:**
   ```
   npm run new <name>
   ```
   Він створює `src/<name>.html`, `src/components/pages/<name>/` (html, scss, js) і PHP-шаблон для WordPress. Якщо проєкт не на WordPress — видали створені `src/wordpress/fls-theme/pages/<name>.php` і `src/wordpress/fls-theme/components/<name>/`.

3. **Заповни `locals` у `src/<name>.html`:**
   - `title` — унікальний, до 60 символів;
   - `description` — унікальний, до 160 символів;
   - `lang` — мова сторінки (`uk`, `en`…);
   - `noindex` — `"true"` для 404, «Дякуємо», службових сторінок;
   - `ogTitle`, `ogDescription`, `ogImage` — лише якщо прев'ю в соцмережах має відрізнятись від `title`/`description`.
   Не видаляй жодного поля, яке використовує шаблон (`noindex`, `lang`…): відсутнє поле ламає збірку сторінки.

4. **Шаблон.** За замовчуванням — `main`. Для сторінок із бічною колонкою — `inner` (`<template src="@components/templates/inner/inner.html">` і блок `aside`).

5. **Вміст** — у `src/components/pages/<name>/<name>.html`. Рівно один `h1`, далі `h2`/`h3` без пропусків рівнів. Секції — компонентами (скіл `fls-component`).

6. **Меню.** Додай пункт у `src/components/layout/menu/menu.html` (масив у `<each loop=...>`), а в `header` сторінки передай `locals='{"active":"<назва пункту>"}'`, щоб пункт був активним. Сторінки 404 і «Дякуємо» в меню не додавай.

7. **Перевір:**
   - `npm run build` — без помилок, у SEO-звіті для сторінки немає помилок;
   - `npm run dev` — сторінка відкривається, є в навігаційній панелі, адаптив до 320px.

8. **Звіт:** створені файли, заповнені SEO-поля, де додано пункт меню.
