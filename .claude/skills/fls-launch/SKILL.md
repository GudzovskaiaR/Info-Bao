# Перевірка перед запуском

Проєкт: $ARGUMENTS

Нічого не публікуй і не вивантажуй (`deploy`, `wpdeploy`, `git`, `zip`) — лише перевір і звітуй. Кожен пункт: ✅ готово, ❌ треба виправити (що саме), ⚠️ не вдалося перевірити (чому).

## 1. Налаштування збірки (`template.config.js`)
- `seo.enable: true`, заповнені `seo.url` (бойова адреса), `seo.siteName`, `seo.ogImage`; `seo.indexable: true` для бойового домену (`false` — лише для тестового).
- `navpanel.build: false` — навігаційна панель не потрапить на сайт.
- `logger.console.removeonbuild: true` — службові логи прибрані.
- `devcomponents` — сторінка компонентів у збірку не потрапляє (перевір, що її немає в `dist`).
- `ftp`, SMTP та інші доступи не записані в файли, які передаються клієнту чи в публічний репозиторій.

## 2. Збірка
- `npm run build` проходить без помилок.
- SEO-звіт: немає помилок (`✗`); попередження розібрані.
- У `dist` є `sitemap.xml`, `robots.txt`; у `robots.txt` немає `Disallow: /` для бойового сайту.

## 3. Сторінки
- Кожна сторінка: унікальні `title` і `description`, один `h1`, правильний `lang`.
- Є сторінка 404 з `noindex`; сторінка «Дякуємо» (якщо є) — з `noindex`.
- Немає тестових текстів («Lorem ipsum», «Текст», «Title number one»), посилань `href="#"` у навігації та заглушок зображень.
- Favicon (`@img/favicon.ico`) — свій, не стандартний.
- Зображення для прев'ю (`og:image`) — jpg/png 1200×630.

## 4. Форми
- Кожна форма відправляється (перевір у `npm run dev`), порожня відправка показує помилки біля полів.
- Обробник налаштований: `src/php/sendmail/config.php` (SMTP) або `src/php/telegram/index.php` (токен, chat_id) — значення заповнені, але не показуй їх у звіті.
- Є повідомлення про успішну відправку.

## 5. Адаптив і доступність
- Перевір сторінки на 1920, 1200, 992, 768, 375, 320 (можна субагентом `fls-qa`).
- Клавіатура: Tab доходить до всіх елементів, фокус видно, меню і попапи закриваються Esc.
- Пройди рев'ю скілом `fls-review` (або субагентом `fls-reviewer`) для сторінок, змінених останніми.

## 6. WordPress (якщо проєкт на WP)
- Пароль адміністратора змінено з локального `123456` на надійний — **обов'язково перед перенесенням на хостинг**.
- `WP_DEBUG` вимкнено на бойовому сайті.
- Налаштування → Читання: «Попросити пошукові системи не індексувати» вимкнено на бойовому сайті.
- Виконано `npm run wpbuild` і `npm run wpblocks`.

## 7. Підключення
- Аналітика (GA4, GTM, Clarity тощо), якщо клієнт її просив, — підключена й вмикається після згоди на cookies, якщо сайт працює з ЄС.
